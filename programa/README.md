# Programa `escuela` (Anchor)

`src/lib.rs` es el programa de Solana del proyecto. Se compila y despliega en Devnet desde [Solana Playground](https://beta.solpg.io/): pega el archivo en el `lib.rs` de un proyecto Anchor, pulsa **Build** y luego **Deploy**. Playground llena el `declare_id!` con el Program ID del despliegue.
